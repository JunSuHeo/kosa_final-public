- 루트 AGENTS.md, PRJ/agents/project.md, .agents/workflow/README.md, .agents/workflow/JS/README.md.

## 계획

1. 로컬 설정·예시·Git 제외 추가 → JS 경로 일치와 Git 제외 확인.
2. 공통 지침·초기 설정법·작업 목록 갱신 → 1~4절 보존과 링크 확인.
3. 문서 정적 검증 → 실제 결과와 미실행 항목 기록.

## 판단·진행 요약

- 개인 담당자는 Git 제외 파일에 두고 공통 지침에는 읽기 규칙만 둔다.
- 공유 예시는 미설정 상태로 두어 다른 팀원을 JS로 잘못 지정하지 않는다.
- 담당 정보가 없더라도 현재 대화에서 명시된 값이 있으면 같은 질문을 반복하지 않는다.
