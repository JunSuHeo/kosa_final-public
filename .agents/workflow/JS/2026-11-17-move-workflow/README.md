- 공동 작업의 대표 기록·관련 팀원 기록: 해당 없음
- 목표: 작업 기록 전체를 `.agents/workflow/`로 옮기고 관련 문서·스킬·개인 설정의 경로를 맞춘다.

- 변경 범위: 기록·하네스 지침·개발 안내·개인 식별 경로. 서비스 소스는 변경하지 않는다.
- 코드 기준: main, HEAD `cda60b152f996b533d29a07d23798fd74921f3a1`. 커밋·push는 수행하지 않았다.

## 읽은 근거

- AGENTS.md, PRJ/AGENTS.md, .agent-local.md와 공유 예시.
- PRJ/agents/project.md·infra.md와 기존 작업 기록·공용 스킬.
- kosa-verify·kosa-handoff를 읽고 이동 검증·인계에 적용한다.

## 계획

1. 파일 목록·원본 경로 확보 → 기존 기록 누락 여부 비교.
2. workflow 전체 이동·상대 링크 재계산·기록 경로 수정 → 기존 경로 잔존 검사.
3. 문서·스킬·원문 보존 검증 → 실제 결과 기록.

## 판단·진행 요약

- 목적지는 `.agents/workflow/`이며 JS/SY/SW와 공통 기록의 내부 구조를 유지한다.
- 과거 기록도 본문 내용은 유지하고 경로 표기·링크만 새 위치에 맞춘다.
- 사용자 요청에 따라 개인 설정의 기록 경로도 갱신하며 JS 식별은 유지한다.
