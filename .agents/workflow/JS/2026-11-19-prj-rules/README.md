# PRJ 개발 규칙 경로 변경

- 담당 팀원 JS, 작업 에이전트 Codex
- 목표는 제품 영역별 개발 지침을 `PRJ/rules/`에서 관리하도록 바꾸는 것이다.
- 완료 조건은 기존 문서 4개를 옮기고 현재 지침과 링크에서 새 경로를 사용하도록 하는 것이다.

## 계획

1. 기존 문서의 파일 내용과 참조 위치를 확인한다.
2. `PRJ/rules/`로 이동하고 현재 경로 참조를 바꾼다.
3. 문서 보존, 이전 경로 제거, 새 링크를 검증한다.

## 변경과 검증

- `project.md`, `frontend.md`, `backend.md`, `infra.md`를 `PRJ/rules/`로 옮겼다. `project.md`의 경로·역할 표기만 갱신했으며 나머지 세 문서는 해시가 이동 전과 일치한다.
- 루트와 `PRJ`의 `AGENTS.md`, 공용 작업 기록 안내에서 개발 규칙을 읽고 갱신하는 경로를 바꿨다. 과거 작업 기록의 당시 경로 표기는 보존했다.
- 로컬 링크 30개와 현재 지침의 이전 경로 참조 제거를 확인했다. `git diff --check`를 통과했다. 문서 변경으로 서비스 테스트는 실행하지 않았다.
