# 스킬 추가 후 모의 검토

검토 에이전트는 팀 전용 스킬을 읽고 추가 전과 같은 가상 PR 세 건에 검증 명령을 골랐다. 승인 UI와 저장 계약 변경에서 변경된 흐름의 E2E 커버리지와 mock 계약 검사 명령을 확인했다. 문구·문서 변경은 프런트 빌드와 문서 점검을 선택하고 필요한 E2E가 막히면 사유를 보고했다. 백엔드 소유권·승인 변경은 격리 테스트와 401·404·409 및 revision 규칙을 연결했다. 과거 실행은 현재 결과와 구분했다. 스킬의 상대 링크 네 개도 확인했다. 파일 편집이나 실제 검사는 맡기지 않았다.
