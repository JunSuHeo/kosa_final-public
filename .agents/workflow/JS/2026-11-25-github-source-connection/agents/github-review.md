# GitHub 연결 코드 리뷰

- 참여: Codex 리뷰 에이전트
- 범위: 구현 diff 읽기 전용 검토. OAuth 계정 바인딩, 토큰 사용·갱신, 등록 화면 복귀, 외부 API 호출량.
- 발견: GitHub App 권한 밖의 기존 저장소에서 서버 토큰이 가려짐. 연결 토큰을 갱신할 때 원격 장애가 기존 저장소에도 전파됨. 화면 재진입 시 승인 결과가 다시 처리됨. 저장소 검색의 전체 호출 시간 제한과 브라우저 등록 정보 파싱 오류 처리가 필요함.
- 반영: 초기 저장소 접근 실패 시 기존 자격증명 사용. 갱신 실패 시에도 기존 접근 방식 사용. 콜백 한 번 처리 및 읽을 수 없는 등록 정보 복구. 저장소 검색 전체 시간과 결과 개수 제한.
