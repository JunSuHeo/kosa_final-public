# 3일 사용성 평가 기록

합의일: 2026-11-10. 기간: 2026-11-10~2026-11-12, 하루 최소 1개 프로젝트.

실제 사용자가 제품을 사용하고 기록한다. 자동 브라우저 검사와 구분하며, 비밀번호·토큰·개인정보는 적지 않는다. 기간 중 사용하지 못한 날은 수행하지 않았다고 표시하고, 실제 사용한 3일이 채워질 때까지 이어간다.

## 매일 수행할 흐름

1. 실제 목적이 있는 아이디어로 프로젝트를 만들고 질문에 답한다.
2. PRD·기능명세·유저플로우·와이어프레임을 읽고 누락이나 모순을 확인한다.
3. 초안을 검토·승인하고 AI 수정 또는 직접 편집을 한 번 수행한다.
4. 역할 검토의 근거를 눌러 지적이 타당한지 판단한다.
5. 새로고침 또는 재접속 후 상태를 확인하고 과거 버전 조회·복원 제안·거절 흐름을 사용한다.
6. 데스크톱과 모바일에서 같은 프로젝트를 조회한다.

2026-11-10 사용자 답변: `아직 실제 사용하지 않음`. 이날은 실제 사용 3일에 포함하지 않는다. 이후 실제 사용한 날짜로 기록을 이어간다.

같은 날 사용자가 홈에 직접 접속해 기준 프로젝트 선택 영역이 화면과 이질적이라고 보고했다. 다크 테마 배경·텍스트 대비를 맞추고 프로젝트 선택과 아이디어 입력을 한 카드에 통합했다. 데스크톱과 모바일에서 등록 폼 열기와 긴 프로젝트명이 있을 때의 가로 넘침도 검증했다. 홈 접속 관찰은 확인했으며 위 전체 일일 흐름을 수행한 기록은 아직 없다.

문제가 있으면 아래 양식을 추가한다.

```text
날짜 / 프로젝트:
기기 / 브라우저:
하려던 작업:
재현 순서:
기대 동작:
실제 동작:
영향과 우선순위:
관련 화면·근거 ID:
```

## 완료 기준

- [ ] 실제 사용 기록 3일분이 있다.
- [ ] 생성·편집·검토·재접속·복원을 사용했고 데스크톱과 모바일을 모두 확인했다.
- [ ] 문제별 재현 절차·영향·우선순위와 후속 수정 여부를 정리했다.

자동 검증 결과는 [verification.md](verification.md)에 별도 기록한다. 이 양식을 준비한 것만으로 장기 평가를 완료 처리하지 않는다.
