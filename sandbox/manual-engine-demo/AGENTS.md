# 테스트 프로젝트 작업 지침

- 목적은 수동 실행 엔진의 변경 생성·결과 수집 시험이다. 최종 제품은 `PRJ/`이며 이 데모와 분리되어 있다.
- 현재 계약은 `specs/design.md`에 있다. 구현 전에 확인하고 계약 변경 시 코드·테스트와 함께 갱신한다.
- 수정 대상은 이 프로젝트의 `src/`, `tests/`, `specs/`뿐이다.
- `PRJ/`, `workflow/`, `.git`, 인증 파일과 이 작업 지침을 수정하지 않는다.
- Python 표준 라이브러리만 사용하고 패키지 설치, 네트워크 접근, Commit, Push, Branch·PR 생성은 수행하지 않는다.
- Unit Test와 CLI E2E 테스트는 프로젝트 설정의 `cwd`와 명령을 그대로 사용한다. 실패나 미실행을 통과로 보고하지 않는다.
- 외부 경로가 아니라 격리 workspace의 저장소 상대 경로를 사용한다. 원본 프로젝트로 변경을 적용하지 않는다.
