# 수동 실행 엔진 테스트용 계산기 설계

이 프로젝트는 `workflow/` 수동 실행 엔진의 변경 생성·수집을 시험하기 위한 독립된 Python CLI다. 최종 적용 대상인 `PRJ/`와 제품 데이터에 의존하지 않는다. Python 3.12 이상과 표준 라이브러리만 사용한다.

## 현재 동작

- `src/calculator.py`의 `add(left, right)`는 두 정수의 합을 반환한다.
- CLI는 두 개의 위치 인자 `left`, `right`를 정수로 받는다.
- 정상 실행은 결과 정수와 줄바꿈을 출력하고 종료 코드 `0`을 반환한다.
- 음수와 0, Python이 지원하는 큰 정수를 처리한다.
- 누락되거나 정수가 아닌 인자는 argparse 오류로 종료 코드 `2`를 반환한다.
- 파일, 네트워크, 외부 서비스, 환경의 비밀정보에 접근하지 않는다.

```bash
python3 -B src/calculator.py 3 5
# 8
```

## 수정과 검증 규칙

변경은 승인된 사용자 요청에 한정한다. CLI 계약이 바뀌면 이 문서와 Unit Test, E2E 테스트를 함께 갱신한다. 테스트를 제거하거나 필수 검사를 생략해서 성공으로 보고하지 않는다. 패키지 설치와 GitHub 연동은 필요하지 않다.

Unit Test는 함수의 동작을 검증한다. E2E 테스트는 실제 별도 Python 프로세스로 CLI를 실행해 입력, 표준출력, 종료 코드를 검증한다. 브라우저를 사용하지 않는 CLI 프로젝트이므로 웹 E2E 도구를 도입하지 않는다.

## 첫 변경 요청 예시

“계산기에 `--operation subtract` 선택지를 추가해 줘. 옵션을 생략하면 현재처럼 더하기를 수행해야 해. 설계문서와 Unit/E2E 테스트도 갱신해 줘.”

이 선택지는 아직 구현하지 않았다. 위 요청을 수동 엔진에 전달한 뒤, 후보 workspace에서 코드·설계문서·테스트가 함께 변경되었는지 확인하는 용도다.
